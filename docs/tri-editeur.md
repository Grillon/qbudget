# Trier le tableau et afficher davantage de lignes (0.19.10)

Dans l’éditeur, cliquer sur un en-tête **Date**, **Compte**, **Élément**, **Montant** ou **Catégories · tags** : le premier clic trie par ordre croissant ↑, le suivant par ordre décroissant ↓. Les boutons sont aussi utilisables au clavier avec Entrée ou Espace. Les colonnes de sélection et d’action « Modifier » gardent leur fonction habituelle.

Le tri porte sur **toutes les correspondances filtrées**, avant de limiter le nombre de lignes affichées. Les montants sont comparés numériquement avec leur signe ; les textes suivent un ordre français tenant compte des nombres (`École 2` avant `École 10`). Les tags sont triés selon leur texte affiché, y compris ceux des associations. Les valeurs absentes, notamment les dates des flottantes, restent en fin de liste dans les deux sens. Les égalités conservent l’ordre initial.

Le choix **Lignes par affichage**, au-dessus du tableau, propose **120, 250, 500 ou 1 000** lignes. Le bouton **Afficher … éléments supplémentaires** ajoute ce même nombre. Une recherche ou un nouveau filtre repart du nombre choisi ; le tri reste actif. Changer le nombre affiché ou le tri conserve la sélection, y compris les opérations sélectionnées qui ne sont plus dans les premières lignes affichées.

La sélection Shift suit le nouvel ordre du tableau. Les actions de taggage utilisent toujours les identifiants des opérations sélectionnées ou toutes les correspondances, jamais leur numéro de ligne. Les filtres Sans tags et Libellés partiellement tagués restent combinables avec le tri et l’affichage progressif.

Ces réglages concernent la vue pendant la session. L’ordre des opérations dans les données et les exports, les annotations, les montants et les calculs financiers restent inchangés.
