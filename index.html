Tests et explorations dans la console du navigateur

Ouvre la console (F12) après avoir chargé la démo. Ces commandes sont en lecture seule :

qbudget.help() · qbudget.test() · qbudget.demo() · qbudget.pending(["SASU", "IK"]) · qbudget.forecast("Qonto") · qbudget.recurrences() · qbudget.impact()

Les tests de la démo concernent uniquement les données fictives. Les commandes n’enregistrent aucune modification.

Éditeur de données · même qbudget

Les montants, comptes, règles et annotations sont ceux du tableau de bord. Les identifiants internes sont préservés mais masqués par défaut. Les opérations bancaires restent dans le CSV ; leurs annotations et les opérations manuelles sont dans le JSON natif.

Les modifications sont enregistrées dans le même état local. Exporte un nouveau fichier après édition ; le fichier d'origine ne sera pas écrasé.
