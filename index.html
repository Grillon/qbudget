Tags · catégories et dimensions du tableau

Saisis les tags librement sur une opération. Ici tu définis à quelle catégorie chacun appartient. Les onglets au-dessus du graphique règlent uniquement son ordre de lecture. Projet et Finalité sont disponibles sans modifier les tags existants. Les boutons radio ne changent que le camembert. Les tags inconnus restent visibles.

Pour distinguer les usages : loisirs reste un poste ; contexte_loisirs décrit le contexte ; finalite_loisirs et finalite_quotidien décrivent la finalité. Le tag remboursement reste un traitement. Les flux calculés et la fréquence détaillée seront ajoutés ultérieurement. IK et noteDeFrais gardent leur classement actuel dans Poste ; Variabilité reste disponible.

Éditeur de données · même qbudget

Les montants, comptes, règles et annotations sont ceux du tableau de bord. Les identifiants internes sont préservés mais masqués par défaut. Les opérations bancaires restent dans le CSV ; leurs annotations et les opérations manuelles sont dans le JSON natif.

Les modifications sont enregistrées dans le même état local. Exporte un nouveau fichier après édition ; le fichier d'origine ne sera pas écrasé.

Transferts intercomptes · 0 à examiner

Même date, même devise, montants exactement opposés et comptes distincts : ce sont des propositions à vérifier. Valider ajoute le tag transfert_intercomptes aux deux lignes, sans modifier les montants ni les soldes. Les doubles débits ne sont pas rapprochés. Si plusieurs contreparties sont possibles, aucun choix automatique n’est fait.

Associations de libellés → tags

Associe plusieurs mots ou expressions à un tag existant : un motif par ligne, avec une condition OU. Recherche littérale, insensible à la casse, par mots entiers. Les libellés et les tags manuels restent intacts. Les associations s’appliquent aussi aux futurs imports.

Un tag absent de la liste peut être ajouté dans les catégories ou sur une opération. Pour modifier un tag issu d’une association, modifie cette association.

Ces associations sont incluses dans l’export des annotations JSON.
